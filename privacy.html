Privacy Policy - assistant

assistant is used only by its owner (stoyanov.dimo@googlemail.com).

  • Use: it reads the owner's Gmail and Google Calendar, read-only, for the owner's personal organisation only. It cannot send, change or delete anything.
  • Storage: the data is processed and stored on the owner's private server at home. Only short derived records (such as a subscription's name, price and renewal date, never message text) are written to the owner's own Notion workspace.
  • Sharing: Google data is not sold, shared with third parties or read by anyone but the owner. Use of Google API data follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Deletion: the owner can revoke access at myaccount.google.com/permissions and delete the stored data at any time.
